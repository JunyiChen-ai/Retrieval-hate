## 0. 规则冻结(写在算任何数字之前)

本节在读取任何面板投票分布、任何重算结果之前写定并提交(commit `8b4a792`,
该提交里只有本节;哈希是提交后回填的,规则文字未改)。后续小节只填数,不改规则。

### 0.1 面板构成

对 `r5_buckets.json` 里 49 个 S(立场 / use-vs-mention)错误项,构造 4 票的「独立判断者面板」:

| 投票者 | 来源 | 输入 | 口径 |
|---|---|---|---|
| r7k | `claude_stance_gate/annot_r7k/*.jsonl` | 转录 + 8 帧(有帧数据集) | 原生二值 ENDORSE / DISTANCED |
| m3q | `claude_stance_gate/annot_m3q/*.jsonl` | 同上 | 同上 |
| z9x | `claude_stance_gate/annot_z9x/*.jsonl` | 同上 | 同上 |
| qwen-R2 | `mask_stance_pilot/pred_m1.jsonl` | 遮蔽转录 + 8 帧 | 五类二值化:`endorses` → ENDORSE,其余四类 → DISTANCED(沿用 `contrast_stance/score_contrast.py::binarise_5way`) |

不入面板的两轮及理由:
- **qwen R1**(`stance_pilot/pred_strong.jsonl`)二值化 0.500,劣于 R2 的 0.5625;每个模型只取其最好一轮,避免同一模型占 2/5 票。
- **qwen R3**(`contrast_stance/pred_c1.jsonl`)是近乎常数的 ENDORSE 预测器(S_FP 1/18,S_FN 14/14),按任务指令不计入。

金标口径沿用 `claude_stance_gate/score_gate.py`:S_FP 的金标 = DISTANCED,S_FN 的金标 = ENDORSE。

### 0.2 三分类定义

设某项有效票数 n(缺票 / 未解析票不计入 n),其中支持金标方向 k 票:

- **可回收项(RECOVERABLE)**:n = 4 且 k ≥ 3;或 n = 3 且 k ≥ 2。
- **争议项(CONTESTED)**:n = 4 且 k ≤ 1;或 n = 3 且 k ≤ 1。
- **分裂项(SPLIT)**:n = 4 且 k = 2(2-2)。
- n ≤ 2 的项:不存在(检查后若出现,单列 `INSUFFICIENT` 并在奖励重算中按争议项处理,即不计入可回收)。

`MHC_zh/BV1m8411z7mV` 因 DashScope 内容审核拒答而无 qwen 票,n = 3,按上式处理。

### 0.3 奖励重算口径

复用冻结的 `r5_bucket_value.py` 计算方式,不改任何一行逻辑,只改选择集合:
同一份 round-4 最优 ensemble 比较器(HateMM/mlp、MHC/mean_logit、MHC_zh/logistic、
ImpliHateVid/logistic)、同一份 seed 预测重建、同一份 test 标签,把
`z[sel] = y[sel]` 的 `sel` 从「该数据集全部 S 项」换成「该数据集的可回收 S 项」,
重算 macro-F1 增量。base 与 §9.2 的 base 必须逐位相同,否则本节作废。

**为什么争议项不计入**:争议项上,面板 4 个独立判断者里 ≥3 个从内容里读出的立场方向与金标相反。
若未来的立场方法真的做对了立场判断,它在这些项上会输出与金标相反的方向,
监督信号会把模型往错误方向推,而不是修好这一项。因此「完美立场方法」的可达上限只包含可回收项。
分裂项按「一半」不做加权处理——单独列出,给出「含分裂项」与「不含分裂项」两个数,
主表用**不含分裂项**的保守数。

### 0.4 定价判定线(现在冻结)

以 4 数据集**均值**的可回收 oracle 相对 §9.2 原 S 桶 oracle(mean +6.46)之比 R:

- R ≥ 0.60 → **值得**做 750 条人工标注。
- 0.40 ≤ R < 0.60 → **边缘**。
- R < 0.40 → **不值得**。

比值用「不含分裂项」的保守数计算;含分裂项的数作为敏感性一并报告,不改判定。

## 5. 交叉检查

### 5.1 与 A 桶(标注分裂,9 项)的重合

**主桶层面重合 = 0**。`r5_buckets.json` 每项只记一个主桶,A 与 S 互斥,所以 9 个 A 项没有一个在
这 49 项里。次桶记录里有 4 个 S 主桶项带 A 次桶:
`MHC/YDEsYXYlB8o`(可回收)、`MHC/pofgIFZpR7c`(可回收)、`MHC/8zLoOqXvk64`(**争议**)、
`MHC_zh/BV1to4y177df`(可回收)。即 4 个里只有 1 个落在争议侧。

### 5.2 争议项是不是「人类标注者自己也分裂」的那些项

MHC-EN / MHC-ZH 有逐标注者原始投票,可以直接检验(28 项中 28 项有票):

| 类别 | n | 人类标注分裂 | 分裂率 |
|---|---|---|---|
| 可回收 | 16 | 7 | **0.438** |
| 争议 | 10 | 3 | **0.300** |
| 分裂(2-2) | 2 | 2 | 1.000 |

**争议项并不比可回收项更容易让人类标注者分裂,反而略低。**
争议项不是「人类也说不清」的那批;在这些项上人类标注者内部相当一致,只是与面板反向。
(n 很小,0.438 vs 0.300 的差本身不显著;能确定的只是「没有正向富集」。)

### 5.3 争议项是不是集中在 ImpliHateVid

**不是。** 争议占比 HateMM 62.5 % > ImpliHateVid 46.2 % > MHC-EN 37.5 % > MHC-ZH 33.3 %。
最高的是 HateMM(n=8,基数小),ImpliHateVid 排第二。
隐性仇恨数据集不是争议的唯一来源,四个数据集都各自贡献了 1/3 到 2/3 的争议率。

### 5.4 争议项的失败形态与可回收项不同

三个 Claude 标注者 voice 多数票为 `none`(即「没看出有攻击性内容」)的比例:
可回收项 14/26 = 0.538,争议项 6/21 = 0.286。
**争议项的主要失败形态不是「没看见」,而是「看见了但判成反方向」**:
21 个争议项里 15 项 qwen 判 `endorses`、只有 4 项判 `no_hate_content`。
这与 CLAUDE_STANCE_GATE §5「失败点在感知层」的结论并不矛盾——那条结论覆盖的是全部 49 项,
而在争议子集里,起主导的是立场方向本身的分歧。

## 6. 定价结论

**R = 3.23 / 6.46 = 0.500**(含分裂项 0.565)。
按 §0.4 冻结的判定线(≥0.60 值得 / 0.40–0.60 边缘 / <0.40 不值得):**边缘。**

拆开说这个 0.500 意味着什么:

1. **750 条里能买到的是 +3.2 macro-F1 均值,不是 +6.5。** 上限直接砍半。
   逐数据集不均匀:MHC-ZH 保住 0.563,MHC-EN 0.487,ImpliHateVid 0.527,
   **HateMM 只保住 0.354(+1.23 点)**——HateMM 上做立场标注基本买不到东西。
2. **+3.2 仍然大于项目里其它任何单个桶。** 同口径下 O 桶(屏幕文字)全项 oracle 四数据集均值 +0.59、
   M 桶(无语音)+0.90(`r5_bucket_value.json`)。即使砍半,立场仍是最大的一块。
3. **这 +3.2 是 oracle 上限,不是方法能拿到的数。** 它假定人工标注 100 % 正确、
   且下游方法把每个可回收项都翻对。任何实际方法只能拿到其中一部分。
   §9.1 的口径下,一个能拿到上限一半的方法对应 +1.6,那已经落在 seed 噪声的量级附近。
4. **争议项不是纯噪声,有一部分是可以靠标注指南收回的**(4.3 / 4.4 / 4.5 三例都属于
   「面板按身份攻击判、数据集按物化/隐性贬低判」)。如果 750 条人工标注**明确要求标注者
   复刻各数据集原始口径**(而不是给出独立的立场判断),R 会高于 0.500;
   但这条无法从现有材料量化,只能作为定性上行空间。
   反方向的风险同样存在:人类标注者可能像 4.1 / 4.2 那样与内容证据反向,
   把 26 个可回收项里的一部分也标成反方向,使 R 低于 0.500。

**给用户的一句话**:出这笔钱买到的期望上限是 **+3.2 macro-F1 均值(HateMM 上只有 +1.2)**,
不是报告里那个 +6.5;这个数落在「边缘」档,不构成自动的 GO,也不构成自动的 KILL。
决定性变量是标注口径怎么写——要求标注者复刻数据集口径,这笔钱才可能回到 0.60 线以上。

## 7. 诚实限定

1. **面板 4 个成员全是 MLLM**(3 个 Claude Opus 5 会话 + 1 个 qwen3-vl-plus 遮蔽轮)。
   它们共享大量预训练与对齐倾向,「4 个独立判断者」中的独立性是有限的。
   `CLAUDE_STANCE_GATE` §4 已经测到 3 个 Claude 之间 Fleiss κ = 0.90,
   即这些票的相关性远高于真正独立的人类标注者之间的相关性。
   因此争议项的 21 这个数,更准确的读法是「MLLM 家族系统性地与金标反向的项数」,
   而不是「任何独立判断者都会与金标反向的项数」。
2. **人类标注者可能系统性不同**,尤其在隐性仇恨上。4.3 / 4.4 两例里人类标注者(MHC 原始投票)
   与面板明确反向,而且人类内部一致度高。这直接说明人类在这些项上确实拿得到面板拿不到的东西。
   本分析给出的是**内容可见证据下、MLLM 判断口径能达到的可回收上限估计**,
   不是人类标注实验的替代,也不能当作人类标注上限。
3. **面板拿到的输入比人类标注者少**:8 帧 @512px + ASR 转录(ImpliHateVid 无帧),
   没有完整视频、音轨、发布语境、评论区。4.1 那类需要节目上下文的项对面板天然不利。
4. **n 小**。逐数据集 S 项只有 8 / 13 / 16 / 12 项,§5.2 的 0.438 vs 0.300 之类的对比
   都在个位数计数上,只能作为方向性证据。
5. **oracle 重算继承 §9.2 的全部限定**:单一 round-4 比较器、test 集上的阈值反演、
   3 个 seed 平均。它衡量的是「这些项翻对之后 macro-F1 涨多少」,
   不衡量「有没有方法能翻对它们」。
6. **分裂项只有 2 个**,主表用不含分裂项的保守口径;把它们全算进来 R 从 0.500 到 0.565,
   不跨过 0.60。
