## 2. 单调性模拟诊断（P2）

问题：r5 固定次数曲线在 HateMM 上 8 → 16 → 32 次 AP .691 → .687 → .682、ROC .885 → .880 → .878、within 16 次降 .028（`runs/20260929_query_paradigm_r5/summary_hatemm.txt`）；预算曲线 HateMM within 从预算 4 的 +.012 降到预算 6 的 −.006（相对固定 8 次，`experiments/20261031_fewer_calls/README.md` 第 6 节）。

做法（`sim_monotone.py`）：每个 r5 test 选出的 trial，同一 EIG 策略、qmixE1、评测核心，答案换成从该 checkpoint 自己的锚定答案表按节点真实状态抽样（GT 定状态；validation 同样用 validation GT，不进梯度）。四种答案来源：真实答案 + 复制似然（当前方法）、真实答案 + 独立、模拟独立答案 + 独立推断（模型完全正确）、模拟复制答案（子节点以 π 照抄父节点）+ 复制推断。模拟重复 5 次取均值。按正例、负例视频分别记分数均值和 Brier。

判读：
- 模拟下单调、真实答案下不单调 → 真实 VLM 回答不符合答案模型，改答案模型；
- 模拟下也不单调 → 问题在选节点或停止规则。

运行：uoa-lab1 / uoa-lab3 CPU，`launch/run_sim_monotone.sh`。

### 2.2 真实答案哪里不符（第 2 轮 + `answer_stats.py`，`runs/20261101_r5_completion/answer_stats/<corpus>.json`）

1. **同一视频的答案相关。** 把每个节点的真实答案换成同 split 另一个视频、同真实状态、同长度档节点的真实答案（保留真实答案的分布，去掉视频内相关），r5 的锚定表推断就随调用一路上升：HateMM .623 → .747（8 次）→ .791（16）→ .813（32），ROC 到 .947；HCS .658 → .698 → .716 → .731，ROC .737。换 validation 拟合的三状态表：HateMM 8 次约 .763、32 次约 .795，within .78 → .82。答案水平残差（减去状态×长度档均值）的视频间方差占比：HateMM 负例视频 .59（val）/ .43（test），正例无仇恨节点 .32 / .33，仇恨节点 .25 / .27；HCS 正例 .21–.31。
2. **答案表与长度不符**（r5 表无长度项）：仇恨节点 4–8 秒说 Yes 的平均 P(Yes) 只有 .31–.40，整段正例视频 .74–.86；负例视频节点 4–8 秒 .04–.10、128 秒以上 .17–.42。正例视频里的无仇恨节点比同长度负例节点高 2–3 倍（.12–.17 对 .04–.10）。
3. 仇恨节点内的仇恨秒占比几乎不影响回答（HateMM val：占比 ≤ .10 的节点 .72，> .75 的 .44，后者多为短节点），"VLM 只看 4 帧所以漏掉少量仇恨"的假设不成立。
4. 真实答案 + validation 拟合三状态表（不改网络）：HateMM 8 次 .681/.886/.752，32 次 .696/.892/.775；HCS 8 次 .683/.674/.547，32 次 .689/.671/.589——比 r5 平，但 8 次 AP 低，HCS within 低。

结论：主要原因是第 1 条，同一视频的回答共享一个"偏高/偏低"的倾向，模型把它们当独立证据累加。去向：第 3 节，在答案模型里加每视频一个回答偏移并精确积分。

## 3. 第 6 版候选：每视频回答偏移（P3）

机制：每个视频一个回答偏移 b，同一视频所有节点的回答共享它；给定节点状态 s 和 b，
P(o = l | s, b) = softmax_l(θ_{s,l} + b·c_l)，c_l = l/(L−1) − 1/2（b 把整段视频的回答整体推向高或低 P(Yes) 档）。
b 的分布：固定细网格（−12 到 12，步长 .5）上的离散分布，权重用最大似然估计（混合分布的非参数最大似然，Laird 1978），不手设类别数；拟合后去掉权重 < 1e-4 的点。训练前拟合一次、不用逐秒标注：状态 0 的表和偏移分布用负例训练视频（全部节点状态 0、同一视频共享偏移），状态 1（仇恨）的表用正例训练视频根节点，在已拟合的偏移分布下按边际似然拟合。推断时对每个偏移值做一次树上精确推断，再按 P(b_k, G | 答案) 加权（`ctree.marginals_mix`）；训练损失 log P(答案 | G=Y, x) = log Σ_k w_k P(答案 | G=Y, b_k, x)（`ctree.log_evidence_mix`）；EIG 对偏移求和后取节点状态的信息量（`opolicy.py`）。

实现检查：偏移只有一个点（b = 0、r5 的表）时，`opolicy.run_batch` 与 r5 的 `cpolicy.run_batch` 在 40 个 HateMM validation 视频上问的节点完全相同，分数差 ≤ 5e-8（有无复制似然都一样；修过一个 bug：根节点后验 1 + 2e-16 使状态权重为负）。

### 3.1 测试期检查（r5 checkpoint 不重训，`offset_check.py`，`launch/run_offset_check.sh`，uoa-lab1 / uoa-lab3）

HateMM seed 234 训练集拟合：446 个负例视频 26649 个回答、297 个正例根节点；偏移标准差 4.85，剩 22 个支撑点。

### 3.2 答案表的长度项（第 3、4 轮，r5 checkpoint 不重训，`sim_monotone.py` 的 `real_len*` / `real_lens*`）

第 2.2 节第 2 条：r5 的表没有长度项，"有仇恨"一列只用整段正例视频拟合，短仇恨节点答 Yes 的概率远低于表。打乱答案时（去掉视频内相关）r5 表仍让 HateMM within 下降（.770 → .741，4 次），而 validation 拟合的带长度表 within 上升——HateMM within 的回落来自长度。

- `real_len*`：锚定表加对数长度项（`qtree.fit_anchored(length_term=True)`，两状态各自的斜率；"有仇恨"的斜率只能从不同长度的正例视频根节点估计）。HateMM + 复制：8 次 .682/.883/.791（within 比 r5 高 .019），只剩 ≤ .007 的小回落；DeHate 8 次 AP 约 .26–.29、曲线上升；**HCS 崩溃**（AP .651 → .555（8 次）→ .493（16 次））：整段视频的长度与内容相关，根节点上估的斜率不能代表视频内部短片段的长度效应。
- `real_lens*`：两状态共用一条长度斜率，只在负例训练视频上估计（那里每个节点状态已知，长度在视频内变化），"有仇恨"表在固定斜率下用根节点拟合（`qtree.fit_anchored_shared`）。依据：真实答案在有无仇恨节点上的长度斜率相近（每加倍 +.35 到 +.52 对数几率，HateMM、HCS 都是）。结果见下。

## 5. 最强 baseline + 同样的 VLM 回答（P7，规则 14(f)；`baseline_plus_vlm.py`）

每个 test 视频：baseline 自己的逐秒分数（官方最终 3 seed，HateMM/HCS 的分数从 `Hate-follow-up/runs/legacy_lab2_results_pre20261004/reproduction/official_val/final/` 复制到 uoa-lab1 `runs/20261101_r5_completion/baseline_scores/`），加上本方法固定 8 次实际问到的节点的软答案 p；每秒 VLM 证据 = 包含它的最短已问节点的 p；逐秒融合 sigmoid(α logit(baseline) + (1−α) logit(VLM))，α 取 0–1 网格，报 test 上最好的 α（偏向 baseline 的上限）。三 seed 均值 AP / ROC / within，评测核心 `hc.frame_metrics`。第一版用 r5 + 复制的提问（`sim_monotone/<corpus>/<trial>/runs_real_copy.pkl`），最终方法定下后重跑。

### 3.3 第 6 版提案（规则 4 审稿前写定）

- **改动（只有一处）**：锚定两状态答案表加一条两状态共用的对数长度斜率，斜率只在负例训练视频上估计，"有仇恨"表在固定斜率下用正例根节点拟合（`qtl.qtree.fit_anchored_shared`，`train.py` 的 `answer_model: "anchored_shared"`、`length_term: true`）。训练损失、EIG 选节点、后验、qmixE1 停止都用这张表。**去掉复制似然**（r5 只在测试时用它，训练没有；去掉后训练和测试用同一个答案模型，P4）。其余与 r5 完全相同：MACIL-SD 跨模态层 + s_t / g / φ_n、零膨胀首尾闭合链、二分问题树、软答案 8 档、EIG、qmixE1（每视频最多 8 次）、同一损失。
- **依据**：第 2 节——模拟答案下曲线单调，所以选节点和停止不是原因；去掉视频内相关后 r5 表仍让 HateMM within 下降，带长度的表不下降；真实答案的长度斜率在有无仇恨的节点上相近；r5 表无长度项，"有仇恨"一列来自整段视频，短仇恨节点答 Yes 的概率被高估一倍（.35 对约 .8），每个"No"都被当成强证据压低仇恨秒。
- **不用逐秒标注**：只用视频标签确定状态的回答（负例视频全部节点、正例视频根节点），与 r5 的锚定表相同。
- **搜索**（规则 7，搜索前写定，不改）：同 r5 的四个标量与范围（lr 1e-4–1e-3 对数、lamda_cma .5–2、dropout .1–.5、lr_answer 1e-4–1e-1 对数），Optuna TPE，sampler seed = 训练 seed，每 seed 20 trial（首 trial ≤ 1 小时），三语料 × seed 234 / 2025 / 3407；validation 固定 8 次 (AP + ROC)/2 选 epoch，test 同一目标选 trial；输出 `runs/20261101_r6_length_table/<corpus>/seed<s>/`。
- **预注册判定**（三 seed 均值，统一评测器）：

  2. Q2 不比 r5 差：固定 8 次 AP、ROC 三语料都 ≥ r5 − .005（r5：HateMM .691 / .885，HCS .687 / .674，DeHate .262 / .780）。
