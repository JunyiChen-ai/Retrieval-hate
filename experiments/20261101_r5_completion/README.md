## 2. 单调性模拟诊断（P2）

问题：r5 固定次数曲线在 HateMM 上 8 → 16 → 32 次 AP .691 → .687 → .682、ROC .885 → .880 → .878、within 16 次降 .028（`runs/20260929_query_paradigm_r5/summary_hatemm.txt`）；预算曲线 HateMM within 从预算 4 的 +.012 降到预算 6 的 −.006（相对固定 8 次，`experiments/20261031_fewer_calls/README.md` 第 6 节）。

做法（`sim_monotone.py`）：每个 r5 test 选出的 trial，同一 EIG 策略、qmixE1、评测核心，答案换成从该 checkpoint 自己的锚定答案表按节点真实状态抽样（GT 定状态；validation 同样用 validation GT，不进梯度）。四种答案来源：真实答案 + 复制似然（当前方法）、真实答案 + 独立、模拟独立答案 + 独立推断（模型完全正确）、模拟复制答案（子节点以 π 照抄父节点）+ 复制推断。模拟重复 5 次取均值。按正例、负例视频分别记分数均值和 Brier。

判读：
- 模拟下单调、真实答案下不单调 → 真实 VLM 回答不符合答案模型，改答案模型；
- 模拟下也不单调 → 问题在选节点或停止规则。
