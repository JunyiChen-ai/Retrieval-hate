## Checked and found correct (no action)

1. **The zero-inflated form is what `up` computes** (`ctree.py:132-135`): `_up` returns V1 = log-weight of the "any = 1" paths with the answer factors and without g, the all-zero chain weight, and lp0 = Σ A3[:, 0]; `up` returns logW1 = g + V1(answers) − V1(no answers), logW0 = lp0, i.e. log P(G = 1, o | x) − log P(G = 0, o | x) = g + log V1(o) − log V1(∅) − lp0 (README 10.2). `log_evidence` (`:200-207`) then gives l1 = log sigmoid(g), l0 = log sigmoid(−g) (length-independent, checks 1 and 5), lo1 = log V1(o) − log V1(∅) = log P(o | G = 1, x), lo0 = lp0. The closed boundary (`:189-193`) multiplies the root table by A(0, first) and A(last, 0) and gives the all-zero path (T + 1) log A00; `logpi` is not used when closed. `_DoubleChain` (`:225-236`) copies all three flags, so evaluation (`marginals`) uses the same form as training.
