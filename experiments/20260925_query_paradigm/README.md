## 2. 方法

### 2.1 问题树与 VLM 答案（输入）

- **问题树**：视频时间轴 [0, T)（1 fps，T = GT 长度）的二分树：节点 [a, b) 在 m = a + ⌊(b−a)/2⌋ 处分成两个子节点，一直分到单秒。二分是定位一个事件所需问题数最少的切分（二分查找），没有 K、J 这类窗口数。
- **可问节点**：长度 ≥ F = 4 秒的节点。每个问题给 VLM 该节点内均匀取的 F 张 1-fps 帧 + 该节点的转录；每次调用的视觉输入相同，所以"调用次数"就是成本单位。F = 4 与旧缓存（K30/K4 每窗 4 帧）相同。
- **问法**：一次调用回答五类有害内容各 0–3 分（hate、harassment、sexual、violence、self-harm；OpenAI moderation 顶层类别，定义与数据集无关）。模型 Qwen2.5-VL-7B-Instruct、贪心、每帧 max_pixels 360×420（与旧缓存相同）。
- **缓存**：`build_tree_manifest.py` 生成 `data/vlm_tree/<Corpus>/manifest.jsonl`（HateMM 63,963 个可问节点，HCS 39,968 个）；`extract_tree_answers.py`（vLLM，campus3 H200）生成 `answers_qwen7b_mod5.jsonl`。训练集全部节点的答案是一次性的离线标注成本；test/val 全部节点缓存只为模拟查询，部署时只调用策略选中的节点，计数按实际选中的节点。

### 2.2 生成模型：零膨胀 OR 树

- 视频状态 G ∈ {0, 1}（视频有害与否），P(G=1 | x) = g。
- 每秒 y_t ∈ {0, 1}。G = 0 时全部为 0；G = 1 时 y_t ~ Bernoulli(π_t) 独立，并以"至少一秒为 1"为条件。
- 节点状态 z_n = 节点内各秒的 OR。视频标签 = G = 根节点状态。
- 答案 o_n（五类各 0–3）只依赖三种状态 s_n ∈ {G=0；G=1 且 z_n=0；G=1 且 z_n=1}，五类在给定状态下独立：P(o_{n,k} = l | s, ℓ_n) = softmax_l(θ_{k,s,l} + ω_{k,s,l} · log ℓ_n)。第二种状态单独建模对应第 1 节 Q3（正例视频中不含仇恨的区间误报率更高）；长度项对应 Q3 的命中率随长度变化。参数 5 × 3 × 4 × 2 个，全部学习。
- **精确推断**：OR 因子只连父节点与两个子节点，树上和积传递是精确的，O(T)。上行传递得 P(答案 | G=1)，下行传递得每秒、每个节点的后验；G 用两次传递的混合处理。数值在对数域计算。
- 最终分数：P(y_t = 1 | x, 已问答案) = P(G=1 | x, 答案) · P(y_t = 1 | G=1, x, 答案)。没有额外先验项、没有外部分类器分数。

### 2.3 骨干：由问题树似然训练的内容先验

- 编码器：MACIL-SD 的音频+文本 / 视觉双流跨模态注意力层（去掉证据编码、key 偏置、上下文项），在 1 秒网格上运行（每行 = 树的一个叶子）。输入：I3D 视觉、VGGish 音频、BERT 文本行（两语料同一配置）。
- 两个头：g = sigmoid(注意力池化后的线性层)；π_t = sigmoid(每秒线性层)。g 负责"视频是否有害"（跨视频排序），π 负责"视频内哪里"。
- **训练目标**：每个训练视频 −log P(Y | x) − log P(该视频全部缓存答案 | G = Y, x) / n_answers，答案项按 2.2 的树精确计算，除以该视频的答案个数使每个视频权重相同（长视频有上千个节点答案；这是按视频加权的似然，不是整个训练集的严格联合似然），梯度经树传到 π、g 与答案模型参数。负例视频上答案项只训练 G=0 状态的答案分布；π 只由正例视频的多尺度答案训练。另加 MACIL-SD 的 CMAL（沿用的骨干部件，权重 λ_cma 在搜索空间里）。
- 骨干不读任何 VLM 答案，训练与测试输入一致；因此不需要训练期选窗、证据 dropout、日程、被遮住答案的预测损失。

### 2.4 提问策略与停止

- 状态：已问的节点和答案。每一步对所有未问的可问节点计算期望信息增益 EIG(n) = I(o_n; (G, y) | 已问) = H(o_n | 已问) − Σ_s P(s_n = s | 已问) H(o_n | s)。因为 o_n 只经过 s_n 依赖 (G, y)，这就是答案对整个未知标注的精确互信息，由一次上下行传递得到的节点后验算出。
- 问 EIG 最大的节点；更新后验；重复。最大 EIG < c（比特）时停止。c 是"一次调用值多少比特"的价格，是部署预算，不是模型超参数：报告 c 从大到小的整条 AP–平均调用次数曲线。
- 主比较点（2026-09-25 按规则 4 审稿意见定，搜索开始前）：**每视频固定问 B = 8 次**（按 EIG 顺序），不含任何在 validation 上校准的量；Optuna 目标与 checkpoint 选择都用它。自适应停止（"最少必要调用"）：c 取在 validation 上平均调用 = B 的值（B = 8、4、2），c 只决定问几次，不改变分数；报告其 test 平均调用次数与分数，并预注册"同平均调用下自适应不低于固定"。

### 2.5 方法级常数

| 常数 | 取值 | 依据 |
|---|---|---|
| 树的切分 | 二分 | 定位事件的最少问题切分；没有窗口数 |
| F（每次调用帧数） | 4 | 每次调用成本相同；与旧缓存相同，便于和 it5 对照 |
| 可问节点最短长度 | F 秒 | F 张 1-fps 帧互不重复的最短区间，由 F 推出 |
| 类别 | 5 类 | OpenAI moderation 顶层类别，与数据集无关 |
| c | 曲线 | 部署预算；主比较点按 B 定 |

## 3. 来源与 novelty（规则 4 审稿 GO，`REVIEW_RULE4.md`）

- 带噪二分查找 / 带噪 20 问题：Jedynak, Frazier & Sznitman 2012；Waeber, Frazier & Henderson 2013（probabilistic bisection）。
- 带噪 OR 网络 / 分组检测解码：Pearl 1988 noisy-OR；group testing 的贝叶斯解码。
- 期望信息增益选问题：Lindley 1956；BALD（Houlsby et al. 2011）。
- 从带噪标注者学真实标签：Dawid & Skene 1979；Raykar et al. 2010（神经先验 + 标注者模型联合似然）。
- 零膨胀模型：Lambert 1992。
- 审稿检索（34 次搜索）：以上均未用于 hateful video detection / localization；最近的任务外先例 VADTree（arXiv 2510.22693：时间二叉树 + 每节点 VLM 打分，训练无关、全节点查询、启发式融合）与 FV-Action（2608.08315：两层均匀网格 yes/no 扫描、固定预算），论文须对照。

- 自适应停止：每步最大 EIG 几乎恒定（HCS 约 .48 比特），EIG 阈值不能区分"还需要问"与"不需要问"；同平均调用下比固定次数差。

### 7.2 改动

1. **先验改为秒级链**（`ctree.py`）：P(y | x) ∝ exp(g·any(y) + Σ_t s_t y_t) · π0(y_1) · Π_t A(y_{t−1}, y_t)，A（2×2）与 π0 学习。仇恨成段出现；"整段无仇恨"是全 0 路径，其概率就是视频为负的概率；负例视频要求全 0 路径概率高，逐秒 logit s_t 在负例上也得到训练。视频标签 Y = any(y)；答案三状态不变。
2. **精确推断**：树节点保存 (首秒状态, 末秒状态, 是否含仇恨) 的 8 个对数权重，两子节点经一次转移合并，O(64T)；每秒与每节点的后验用自动求导得到（∂ log W / ∂ s_t、∂ log W / ∂ η_n）。已对 T ≤ 12 穷举核对（误差 ~1e-16）。
3. **训练目标**：−log P(Y | x) − log P(答案 | Y, x) / n_answers，均在树上精确计算；g 不再单独做 BCE，进入链的 any 因子。
4. **停止规则**（评估期，`stopping.py` / `cpolicy.py`）：仍按 EIG 选问题；停止看所选问题的"输出期望平方变化" VOI = Σ_t E_o[(p_t^o − p_t)²]，用两次钳住节点状态的推断精确计算（已与穷举核对）。在第 0 版 HCS trial 0 上重评：平均 1.24 次调用 AP .669 / ROC .678（固定 8 次 .681 / .679；EIG 阈值平均 2.7 次 .626 / .606）。
5. 评估按视频批量运行（`cpolicy.run_batch`，每步一次批量推断）。

规则 6 复核 PASS（`REVIEW_RULE6_R1.md`，无必须修）。消融 (b) 在链先验下的先验项是无答案时的链后验 P(y_t = 1 | x)（代替 g·π_t）。方法级常数不变（二分、F = 4、五类）；新增的 A、π0 是学习参数。搜索空间、trial 数规则、主比较点（固定 8 次）与预注册 P1–P3 不变；消融 (b)–(f) 在链先验上做，另加 (g) 链先验 → 逐秒独立（第 0 版）。

### 8.3 诊断结论

1. **答案模型随网络联合学习会漂移**：凡是答案模型（或链）用答案似然学习的运行都比初值差（第 1 版搜索 HCS −.02；D1–D4）。D3 学到的链 A(1→1) = .0004（仇恨只持续 1 秒）；学习后的答案模型让答案几乎不改变视频判断（HateMM 视频 AUC 0 → 8 次 .839 → .870，第 0 版 .847 → .913）。原因：只有视频标签时，"哪一秒是仇恨"与"答案模型各状态的含义"不可同时辨识，自由的联合最大似然把隐变量的含义改掉。锚定答案模型只用状态已知的答案估计，不含隐变量。
2. **长度项在短节点外推失败**：状态 1 只在正例根节点上观测到，HCS 根节点 60–350 秒，外推到 4 秒得到 P(hate ≥ 2 | 状态 1) = .002（test 实测含仇恨 4–8 秒节点 .459）。G4 / G5 / G7 在 HCS 都比无长度项低 .02–.04。去掉长度项。
3. **链先验训练稳定，逐秒独立先验训练中退化**：独立先验的 validation 准则在第 3–10 epoch 达到最高后下降（第 0 版两语料最优 trial 取在第 3、5 epoch）；链先验持续上升到第 37–41 epoch（HateMM R1_slow、G1）。HateMM 上链先验的 within .57–.62（独立 .54）。
4. **骨干训练目标**：标签 + 全部答案（VLM 答案作多尺度训练目标）最好；只用标签（G2）HateMM 掉 .09 AP；按策略答案下的后验训练（G6）HateMM 掉 .09。
5. **分数分解**（`score_decomposition.py`，`runs/20260925_query_paradigm/decomposition/<corpus>.json`，开发期 test 分析）：把每个视频的逐秒分数换成该视频均值（只留视频间排序），第 0 版 HCS 从 .685 / .689 升到 .699 / .715，HateMM .617 → .620；it5 反而降（HCS .688 → .682，HateMM .640 → .627）。即本方法的视频内分数对 pooled 是负贡献，it5 是正贡献 +.013（HateMM）。全部节点都问时，VLM 答案本身的视频内 ROC 只有 HateMM .54–.57、HCS .55–.59；it5 不调用 VLM 时 within .647 / .564，其中文本分类器项 x_t 单独的 within HateMM .624。视频内定位主要来自内容模型，不来自 VLM。
6. 用视频后验 P(G=1 | 答案) 作为每个视频的常数分数：第 1 版 HCS trial 1 为 .700 / .713（高于 it5），HateMM .613 / .860。答案对视频级判断有效；差距在视频内。
7. 对答案似然降温（更新时乘 τ，离线，G1 HateMM）：τ = .5 时 8 次 .571 → .590、32 次 .591 → .610。嵌套节点的答案不是条件独立的（同一内容），独立假设使后验过度自信；只作记录，τ 是拍的数，不进方法。

### 10.2 改动

- **零膨胀链**（`chain_form "zero_inflated"`，`ctree.up`）：P(G = 1 | x) = sigmoid(g)，与视频长度无关；G = 1 时各秒服从首尾闭合的链（一元势 s_t），并以"至少一秒有害"为条件；G = 0 时各秒全为 0。P(G = 1 | 答案) 的对数几率 = g + log V1(答案) − log V1(无答案) − 答案在状态 0 下的对数似然，V1 = 链上"至少一秒有害"路径的总权重。这是第 0 版的零膨胀结构（视频状态单独建模）加上第 1–2 版的链，第 7 节引入耦合链的理由（负例训练逐秒 logit）不再成立。已对穷举核对（T ≤ 9，误差 ≤ 2e-15）。
- 训练目标形式不变：−log P(Y | x) − log P(答案 | Y, x) / n_answers；在零膨胀下第一项只训练视频头 g（BCE），第二项在正例视频上训练逐秒 logit 与链、在负例视频上为常数。
- 其余同第 9 节（锚定两状态答案模型、首尾闭合的学习链、BERT 文本行、EIG、固定 8 次主比较点）。

## 11. 第 4 次修改的设计检查（用户 2026-09-25 22:10 同意开第 4 次修改：三状态答案模型，不用 GT 估计；开发期证据，规则 10）

目标：修 10.4 的"多问变差"与 P2b，不用 GT。五项检查全部只在一个语料有利或两边都不行，**没有进入训练与搜索**：

1. **三状态的无 GT 估法**（scratchpad `depth_hmm.py`）：正例 train 视频里同一深度的节点互不重叠，按时间顺序做两状态 HMM（EM，按节点长度分组），估"正例视频里无仇恨 / 有仇恨节点"的回答"有"的比例。HateMM 4–8 秒估出 .205 / .977（占比 .41），test GT 为 .470 / .567（占比 .64）；HCS .126 / .890，GT .320 / .459；各长度同样。HMM 找到的是"VLM 连续说有的区段"，不是 GT 仇恨；它与锚定两状态模型（负例 .18、正例根 .96）几乎相同。结论：只用视频标签与答案，最大似然给出的就是锚定模型；正例视频内"有仇恨 / 无仇恨"节点的回答差别不可识别，三状态模型没有不用 GT 的估法。
2. **答案似然降温 τ**（测试时，`swap_tau.py`，三 seed 均值 AP / ROC）：HCS τ = .35 时 8 次 .680 / .690、32 次 .681 / .684（不再下降）；HateMM τ = .35 时 8 次 .645 / .863（比 τ = 1 低 .012 AP），32 次 .629（仍低于 8 次）。

## 13. 提议修正的离线检查：按骨干特征在视频内传播答案（2026-09-26 08:30；`propagation_check.py`；开发期证据，规则 10）

背景：用户指出骨干没有和 VLM 紧密结合（第 12 节无骨干对照在 HCS 上不掉）。我提出的修正是"每个视频修正骨干的打分头"：VLM 确认或否定一个区间后，按骨干特征把这个结论传到同一视频里特征相似的其它秒。修正生效的前提是骨干特征能把一个区间的结论传到别处。

做法：
- **视频：** 每个正例 test 视频（同时含两类秒）取至多 5 对长度 4–15 秒的树节点 (P, N)。
- **两种设定：**
  - `oracle`：P 含仇恨、N 不含，按真实标签选，相当于 VLM 完全答对。
  - `vlm`：P 是缓存 VLM 答"某类 ≥ 2"的节点，N 是五类全 0 的节点，即真实回答。
- **评分：** 对 P、N 之外的秒算视频内 ROC，先对每对取均值，再对视频取均值。
- **排序方式：**
  - `prior`：骨干自己的每秒 logit。
  - `time`：到 N 的距离减到 P 的距离。
  - `feat`：骨干特征 h_t = a_out_t + v_out_t 与 P、N 均值的余弦差（每秒打分头读的就是 h_t）。
  - `feat_c`：同 `feat`，h 先减去视频均值。
  - `raw`：骨干的输入（I3D、VGGish、BERT，视频内标准化）做同样的余弦差。
- **模型：** 第 3 版每个 seed 的最优 trial，结果取三个模型的均值。

| | HateMM oracle | HateMM vlm | HCS oracle | HCS vlm |
|---|---|---|---|---|
| 视频数（对数） | 68 (336) | 60 (281) | 67 (335) | 63 (314) |
| prior | .592 | .581 | .513 | .514 |
| time | .692 | .549 | .653 | .531 |
| feat | .643 | .549 | .602 | .523 |
| feat_c | .655 | .539 | .602 | .534 |
| raw | .712 | .551 | .632 | .546 |

读法：
- **真实标签时：** 按骨干特征传播比骨干自己的打分高（HateMM +.05–.06，HCS +.09），但低于按时间远近（.692 / .653）和按原始输入（.712 / .632）。骨干由视频标签训练，它的特征丢掉了视频内部的区分信息；树和链已有的时间传播比它强。
- **换成真实 VLM 答案时：** 所有传播方式在 .52–.55，HateMM 上都低于骨干自己的打分（.581）。短节点回答的噪声（第 10.4 节）使任何传播都没有信号可传。
- **结论：** 提议的修正在两个语料上都缺前提，不做成方法。DeHate 训完后跑同一检查（`experiments/20260926_dehate_external/README.md`）。

## 15. 第 4 版（提案，2026-09-27；用户要求解决 14.1 的 concern）

### 15.1 改动（其余与第 3 版完全相同：锚定两状态答案模型、首尾闭合的零膨胀链、EIG、主比较点固定 8 次、BERT 文本行）

1. **输入：词级时间戳转录**（规则 5；14.4–14.5）。节点问法、帧、模型不变，节点转录改用 `data/ASR_words/`（`answer_source "words"`）。训练、validation、test 的全部节点重问一次（`answers_words_qwen7b_mod5.jsonl`）。骨干的特征（I3D、VGGish、BERT 行）不变，与 baseline 相同。
2. **骨干：树节点先验势**（`node_prior true`；针对 C4）。第 3 版骨干只给每秒势 s_t 和视频 logit g，树上其他节点的先验只由链从 s_t 推出来。第 4 版把视频头的注意力池化用到树的每一个节点上：节点 n 的池化向量 e_n = Σ_{t∈n} softmax_{t∈n}(w_t) h_t，w_t 是视频头的注意力 logit，h_t = a_out_t + v_out_t。沿树自底向上算（父节点的向量与注意力权重对数和由两个子节点的精确合并得到），根节点的 e_root 就是第 3 版视频头的池化向量，g = vid(e_root) 不变。每个内部节点一个势 φ_n = w_φ · e_n + b_φ（线性层，初值为 0，训练开始时与第 3 版完全相同），进入生成模型作为 G = 1 下的因子 exp(φ_n z_n)：
   P(y | G = 1, x) ∝ exp(s · y) · chain(y) · Π_n exp(φ_n z_n) · 1[any(y) = 1]。
   因子只挂在单个节点的 OR 状态上，树上和积仍然精确（`ctree.up` 与 `eta` 同一位置；对穷举核对 T ≤ 9，误差 < 1e-15），也进入"无答案"的归一化项。训练目标不变：−log P(Y | x) − log P(全部缓存答案 | G = Y, x) / n_answers + CMAL；φ 由每个训练节点的答案直接监督。测试时 EIG 用的节点先验、没问到的节点的后验都带上内容给出的节点势。
   结果：骨干的计算图就是问题树（叶 = 每秒势，内部节点 = 节点势，根 = 视频头），骨干输出的就是生成模型在每个问题节点上的因子，而不是只给每秒和整段两个尺度。没有新的方法超参数。

### 17.2 第 2 步：嵌套答案的复制型似然

- **模型**（`cpolicy.run_batch copy_pi`）：节点 n 与某个已问且有答案的节点 m 嵌套（包含或被包含，取尺度最近者）时，P(o_n | s, o_m) = π·1[o_n = o_m] + (1 − π)·P(o_n | s)。进入候选节点的 EIG 与读到答案后的似然；树推断不变（仍是单节点因子）。子答案与父答案相同时证据被稀释，不同时证据完整；EIG 自动降低「很可能只是复制」的嵌套节点的价值。
- **π 的无标注估计**（`copy_check.estimate_pi_neg`）：负例训练视频全部节点状态为 0，父子对的答案相等率 r = π + (1 − π)·Σ_o P(o | 0)²，解出 π，按子节点长度分 6 档。另报常数 π ∈ {.25, .5, .75} 的敏感性。
- **离线检查**（`copy_check.py`，第 4 版最优 trial，网络不变，test）：通过条件 = 三语料 8 次 AP、ROC 不低于树 − .005，且 HateMM 32 次 ≥ 8 次 − .005 或 8 次 within 高于树 ≥ .01。通过则进入第 1 步的搜索配置（与软答案同时用）；不通过则试变体：π 只作用于 EIG 不作用于似然；复制核放宽为「二值答案相同」；π 按 validation 选一个标量。
