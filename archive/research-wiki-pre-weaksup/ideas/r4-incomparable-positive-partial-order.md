# Incomparable-Positive Partial-Order Head (IPPO)

**stage:** `archived`  ·  **outcome:** `pending`

## Thesis
Treat ImpliHateVid's EX and IM as two incomparable positive strata and optimise only the partial order NH<EX and NH<IM, never spending capacity on the EX-vs-IM confusion.

## Key risks
REMOVED: ImpliHateVid is the only corpus in the project with hate-subtype annotation, so any result is one-dataset; and both the error target (NH false positives) and the functional form came from the same test recon. Jury 4.2/10, clean local diagnostic, not a methods pilot. Likely reproduces group-DRO / balanced pairwise AUC.
