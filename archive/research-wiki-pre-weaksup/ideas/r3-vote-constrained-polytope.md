# Vote-constrained semantic polytope

**stage:** `archived`  ·  **outcome:** `pending`

## Thesis
Each raw annotator vote maps to linear inequalities over latent harm axes, so a vote set defines a feasible polytope; training minimises distance to that set rather than matching a vote histogram, and binary policies are compiled afterwards as half-spaces.

## Key risks
Jury 3.8/10. Hand-authored, underidentified semantic geometry; reads as an elaborate concept bottleneck. Partial-label and superset-label learning are close.
